
# LinkedIn Post Generator

A fast, clean, and customizable LinkedIn post generation web application built with Streamlit and powered by Groq's ultra-fast LLM APIs. Draft targeted, high-converting content tailored to your audience, tone, and desired length in seconds.

---

## Features

* **Tailored Outputs**: Select target audience, post tone, length, and hashtag inclusion.
* **Ultra-Fast Generation**: Powered by Groq-hosted open-source models (Llama 3.3 70B, Llama 3.1 8B, and Mixtral).
* **1-Click Copy**: Built-in clipboard copying directly from the output box.
* **Secure API Handling**: Native support for Streamlit Secrets to keep API keys hidden from public view.
* **Minimalist UI**: Clean interface designed for scannability and quick content creation.

---

## Tech Stack

* **Frontend & Web Framework**: [Streamlit](https://streamlit.io/)
* **AI Provider**: [Groq Cloud API](https://console.groq.com/)
* **Language**: Python 3.9+
